TraceParticles.jl documentation

TraceParticles was created to embed trace/test particles in magnetohydrodynamic environments, or any electromagnetic field. Test particles move independently and their motion is governed by the Lorentz force. This code uses DifferentialEquations.jl to solve the particles' equations of motion.

Basic usage

TraceParticles provides tools to simulate test particle ensembles using the EnsembleProblem from DifferentialEquations.jl. The tools provided by TraceParticles.jl are:

  • Equations of motion (EoMs)
  • prob_funcs for drawing initial conditions and importance weighing.
  • output_funcs for managing the solutions.
  • reduction functions for storing data.
  • callbacks for e.g. determine the validity of EoMs.
  • Post-processing tools for fetching and analysing the data.

See examples for simulations in both analytical and gridded electromagnetic fields, with and wihtout statistical sampling of the particle initial conditions.
